# User guide

The user guide is concept-first prose, organized by topic rather than by
class. It is the place for the why and the when-to-use, separate from
the autogenerated API reference.

```{note}
The guide grows alongside the implementation. The pages below are the
v1 outline; each fills in as its subsystem lands. The authoritative
specification today is the
[requirements doc](https://github.com/switch527/seq-sklearn/blob/main/docs/requirements.md).
```

## Planned topics

- **TFT for supervised learning.** How the forecasting-only TFT is
  adapted to classification and regression: the head swap, the loss
  swap, and what is preserved from the original architecture.
- **The panel data contract.** Entity-by-period input, the
  `(entity_id, period)` key, static and time-varying covariates,
  masking and variable history.
- **`TabularToSequence` preprocessing.** The single shared path that
  feeds every current and future model.
- **Interpretability.** Reading variable-selection weights and temporal
  attention, and the stability guarantees on those outputs.
- **Calibration.** Calibrated class probabilities and conformal
  quantile regression.
- **Hyperparameter tuning.** Optuna as a first-class integration,
  including in-training pruning.
- **Serialization and export.** safetensors plus JSON, and ONNX export
  through the optional extra.

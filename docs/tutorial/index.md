# Tutorial

A single linear path that teaches the library top to bottom on a
bundled synthetic panel. It does not ask you to make any choices.
You will end with a fitted, evaluated TFT classifier and a sense of
what variable selection and temporal attention tell you about a fit.

This page alone is enough to get productive. Once you finish, the
[how-to guides](../how-to/index) cover specific tasks
("how do I extract attention?", "how do I export to ONNX?") and the
[explanation pages](../explanation/index) cover the why.
